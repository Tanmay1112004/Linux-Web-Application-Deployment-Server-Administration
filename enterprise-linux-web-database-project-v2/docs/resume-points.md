# Resume Points

## Enterprise Linux Web & Database Administration — AWS EC2

- Deployed a database-driven Student Management Portal on AWS EC2 using Amazon Linux, Apache, PHP and MariaDB.
- Configured Linux services, filesystem permissions and a least-privilege MariaDB application user.
- Developed Bash automation for service health checks, system reporting and website/database backups.
- Automated backup operations with Cron and practiced database recovery using `mysqldump`.
- Troubleshot HTTP, database, permission, service and networking failures using `systemctl`, `journalctl`, `ss`, `curl` and Apache logs.
- Managed source code and documentation with Git/GitHub while keeping credentials and sensitive backups out of version control.
