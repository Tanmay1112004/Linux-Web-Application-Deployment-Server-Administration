5. Why should port 3306 not be public?

12. How do you troubleshoot an HTTP connection failure?
13. What does `ss -lntp` show?

15. What is least privilege?
16. Why is the DB configuration outside `/var/www/html`?
17. What is a prepared SQL statement?
18. What is `mysqldump`?
19. How does your backup script work?
20. How does Cron automate backups?
21. How would you restore the database?
22. How do you monitor CPU and memory?
23. How do you troubleshoot when Apache works but the application cannot connect to MariaDB?
24. What happens if the MariaDB service is stopped?
25. What would you improve next: HTTPS, CloudWatch, Docker, Terraform or CI/CD?
